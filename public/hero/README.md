# Hero / banner images

Optional. Drop background images for the home hero or section banners here.

## Expected (optional) files

| File              | Used where                        |
|-------------------|-----------------------------------|
| `bg-01.jpg`       | Home hero background (optional)   |
| `about-bg.jpg`    | About page banner (optional)      |
| `contact-bg.jpg`  | Contact page banner (optional)    |

The current hero uses a CSS-only gradient + animated fiber lines and
looks great without any image. Only drop a file here if you want a
photo background.

## File guidelines

- **Format**: JPG (compress hard — these are large)
- **Size**: 1920×1080 or wider; keep under 500KB after compression
- **Dark/light**: If you use a hero image, make sure text remains legible
  — usually a dark overlay or dark photo works best
